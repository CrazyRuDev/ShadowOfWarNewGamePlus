Shadow of War — новая игра+: как собрать программу на своём компьютере

Что нужно установить один раз:
  1. AutoHotkey v2 — https://www.autohotkey.com/  (кнопка Download -> v2).
     После установки откройте AutoHotkey Dash (из меню Пуск) -> Compile:
     он предложит скачать компилятор Ahk2Exe — согласитесь (нужен для версии «один файл»).
  2. Python 3 — https://www.python.org/downloads/
     В установщике обязательно поставьте галочку "Add python.exe to PATH" (нужен для версии «один файл»).

Сборка:
  Запустите build.bat двойным щелчком. Через пару минут в папке dist появятся две версии:
      dist\SoWNGPlus\             — программа папкой: запускать SoWNGPlus.exe
      dist\SoWNGPlus.zip          — та же папка архивом, без ваших данных и настроек — ЕЁ и выкладывать
      dist\single\SoWNGPlus.exe   — программа одним файлом, для себя
  Версию «один файл» антивирусы иногда считают подозрительной (так устроены exe, которые распаковывают
  себя при запуске), поэтому на сайты модов выкладывайте только zip.
  В первый раз build.bat скачает встроенный Python с python.org в папку vendor (около 11 МБ).
  Пересборка не трогает ваши данные игры, летопись и настройки в dist\SoWNGPlus.

Без сборки (для проверки изменений):
  запустите gui\SoWNGPlus.ahk двойным щелчком — окно работает с движком прямо из папки engine
  (нужен Python из пункта 2; данные игры тогда лягут в gui\data).

Первый запуск программы: вкладка «Настройка» -> папка игры -> «Распаковать данные игры».

Папки:
  engine\   — движок (Python)          gui\     — окно (AutoHotkey) и опоры (bases)
  tools\    — служебное для сборки      vendor\  — встроенный Python (скачивается сам)
  dist\     — собранные версии          plugin\  — задел плагина для Mod Loader (отложен)
