# Shadow of War — новая игра+

Программа показывает, что лежит в сохранении (уровень, навыки по веткам, предметы, самоцветы, мирианы),
и собирает сохранение новой игры+: начало новой игры + прогресс Талиона из пройденной.

## Запуск

1. Распакуйте папку `SoWNGPlus` куда угодно и запустите `SoWNGPlus.exe`.
2. Для Steam программа сама найдёт папку игры и самое свежее сохранение, при первом запуске распакует
   из архивов игры базу и русские тексты в папку `data` (около минуты).
3. Для другой версии игры: вкладка «Настройка» — папка игры и «Распаковать данные игры»;
   вверху «Открыть…» — сохранение (`<8 знаков>_ShadowOfWar.sav`).

## Новая игра+

Вкладка «Новая игра+»:

- **Опорное сохранение** — начало новой игры. С программой идут два готовых (папка `bases`): сразу после пролога
  и начало второго акта (первый акт с обучением пройден; перенос на него ещё не проверен в игре).
  Можно выбрать и своё сохранение. Готовые опоры подходят любому пользователю: результат шифруется по имени
  файла, куда он записывается.
- **Пройденная игра** — сохранение, открытое вверху окна.
- **Куда записать** — файл сохранения игры. Заменяемый файл программа копирует в `.bak` с датой.

Переносится: уровень и опыт, навыки (кроме сюжетных — их выдаст сюжет), всё снаряжение, самоцветы и мирианы.
Слоты самоцветов остаются пустыми — обучение в первом акте просит вставить самоцвет.
Перед заменой сохранения отключите облачную синхронизацию Steam для игры.

## Устройство

- `SoWNGPlus.exe` — окно (AutoHotkey v2, исходник `gui/SoWNGPlus.ahk`).
- `engine/sowtool.exe` — движок (Python, исходник `engine/sowtool`), можно запускать и отдельно:

```
sowtool info <сохранение> [--format text|json|tsv]
sowtool ngplus --base <новая игра> --source <пройденная> --out <файл>
sowtool setup --game <папка игры>
sowtool locate                       (Steam: папка игры и самое свежее сохранение)
```

Сборка обоих `.exe` — GitHub Actions (`.github/workflows/sow-ngplus.yml`), результат — архив `SoWNGPlus`
на странице запуска.
